# AIHEAR marka dosyaları

Bu klasördeki iki dosya şimdilik **yer tutucu yazı logolarıdır** (resmi logo değildir).

- `aihear-logo.png` — açık zemin için (koyu renk logo)
- `aihear-logo-white.png` — koyu / mor zemin için (beyaz logo)

Resmi AIHEAR logosunu aynı adlarla, şeffaf arka planlı PNG olarak bu klasöre koyun (yükseklik en az 200 px önerilir).
Uygulama her yerde otomatik olarak yeni logoyu kullanır. Mağaza görsellerini ve tanıtım videosunu yeni logoyla
yeniden üretmek için: `npm run store:assets` ve `npm run promo:video` (bkz. `scripts/marketing/README.md`).
